# Brasileirão Assets v11

## Logos oficiais (92 clubes)
- Pasta: `logos/`
- Zip: [logos_v11.zip](./logos_v11.zip)

## Faces reais (Série C/D parcial)
- Zip: [faces_cd_partial.zip](./faces_cd_partial.zip) (~319 fotos reais do Transfermarkt)
- Extraia em `assets/img/faces/` (nomes no formato `codigo_tmId.png`)

## Instalação no jogo (pasta Drive)
1. Baixe os zips
2. Extraia `logos/` por cima de `assets/img/logos/`
3. Extraia `faces/` por cima de `assets/img/faces/`
4. Recarregue o jogo (Ctrl+F5)

Escudos obtidos do Transfermarkt API. Faces = portraits oficiais TM.
